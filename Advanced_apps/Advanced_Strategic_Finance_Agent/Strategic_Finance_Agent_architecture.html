Presentation Layer

Streamlit dashboard with sidebar inputs (source/target currency, amount, business context) and expandable data source transparency. Status streaming shows each agent's progress in real-time.

  • Source: Strategic_Finance_Agent.py (lines 166-216)
  • Runtime detection: st.runtime.exists() for dual CLI/UI mode

Orchestration Layer

LangGraph StateGraph with typed AgentState ensuring strict data contracts between nodes. Linear DAG flow prevents context pollution across agent boundaries.

  • 3 nodes, 3 edges, 1 entry point
  • State schema: 8 typed fields
  • Additive updates via TypedDict merge

Intelligence Layer & 3-Tier Fallback Architecture

The system uses a circuit breaker pattern with three fallback tiers for FX rate fetching. Each tier tags its output so downstream agents always know the source reliability.

  • Tier 1 (Primary): ExchangeRate API v6 — dedicated FX endpoint, 10s timeout
  • Tier 2 (Fallback 1): Tavily Search — AI-native structured markdown results
  • Tier 3 (Fallback 2): DuckDuckGo — zero-cost always-available safety net
  • Gemini 3.1 Flash Lite provides 1M+ token context window for the CFO strategist

Node 1: currency_data_fetcher

Fetches the latest real-time exchange rate. The 3-tier fallback ensures the pipeline never drops a request.

  • Priority: ExchangeRate API v6 (dedicated)
  • Tavily fallback query: "current exchange rate {src} to {tgt} price today"
  • Output tagged with "[Search Fallback]" if not from API

Node 2: financial_news_analyst

Searches for high-impact financial news across 3 context-aware queries, each targeting a different signal type.

  • Forecast query: 30-day volatility outlook
  • Central bank query: rate decisions & speeches
  • Events query: macro economic calendar
  • All results aggregated into a single news summary

Node 3: senior_strategist

CFO-level advisor invoked with Gemini 3.1 Flash Lite. The prompt includes full context, current rate, and market news.

  • Extracts the likely current rate from raw data
  • Analyzes short-term trend (Bullish/Bearish)
  • Assesses volatility: stable vs shock
  • Outputs "Executive Decision" first, then rationale

State Contract (AgentState)

Strict TypedDict with 8 fields enforces data contracts between nodes. Each node receives accumulated state and returns selective updates.

  • source_currency, target_currency, amount
  • business_context — user's scenario text
  • current_rate — populated by node 1
  • market_news — populated by node 2
  • final_recommendation — populated by node 3

Market Research

Strategic_Finance_Agent.py:58-82

Uses a 3-tier circuit breaker to fetch live FX rates. The primary path is the ExchangeRate API v6 dedicated endpoint; if that fails, it falls back to Tavily, then DuckDuckGo.

News Intel

Strategic_Finance_Agent.py:84-100

Fires 3 parallel-sequential Tavily search queries per invocation. Each query targets a different intelligence domain: forecast, central bank activity, and macro events.

CFO Advisor

Strategic_Finance_Agent.py:102-143

Uses Gemini 3.1 Flash Lite with 1M+ token context. Prompted as a CFO-level advisor with 4 mandatory analysis steps: extract rate, analyze trend, assess volatility, formulate strategy.

Key Design Decision

Sequential DAG vs Parallel: Although rates and news could be fetched in parallel, the sequential design enables context enrichment — the news agent searches "USD EUR at 0.92 forecast" instead of generic queries, producing more relevant results.

Mocking Strategy

Strategic patching replaces three external interfaces:

  • requests.get — returns mock ExchangeRate API JSON
  • TavilySearch.invoke — returns fixed markdown strings
  • BaseChatModel.invoke — returns controlled LLM content
  • No DuckDuckGo mocking needed (never reached in tests)
