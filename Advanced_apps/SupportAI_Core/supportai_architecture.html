Security Layer

The Guardrail node (main.py:221) enforces input safety with 10 regex injection patterns, Presidio URL detection, 6 encoding variant decoders (base64, hex, binary, leet-speak), and a JSON schema scanner. The PII node (main.py:425) uses Presidio + SpaCy to mask PERSON, PHONE, EMAIL, and CREDIT_CARD before data reaches any agent.

Orchestration Layer

10 nodes built with LangGraph main.py:883-941. A Triage agent (DeepSeek V4 Flash via OpenCode Zen) routes to 4 specialist nodes: Technical (RAG-augmented), Inquiry (RAG-augmented), Escalation (policy-engine + HITL), and Off-Topic. Summarization auto-triggers after 8 messages.

Data Layer

RAG pipeline: kb.json (1,137 QA pairs from Bitext dataset) seeded into Pinecone Serverless (768-dim, cosine). Base retriever fetches top-10, FlashRank reranker main.py:373 re-scores to top-3 using ms-marco-MiniLM-L-12-v2. Dual persistence via SQLite + JSONL for dashboard + fine-tuning.

Retrieval

Embedding Pipeline

Uses BAAI/bge-base-en-v1.5 on CPU producing 768-dim vectors with cosine similarity. Encodes all 1,137 KB documents. The embedding model runs locally via main.py:282-293 with a custom wrapper around sentence_transformers.

Vector Store

Pinecone Serverless index (support-kb) in AWS us-east-1. Batch population at 50 docs/chunk with 60s rate-limit backoff. Features a sentinel cache (/tmp/.supportai_pinecone_cache) that skips list_indexes() API call on restarts, saving about 2s.

Cross-Encoder Reranker

main.py:371-373 - FlashRank with ms-marco-MiniLM-L-12-v2. Takes top-10 from Pinecone, re-scores with a full cross-encoder pass, returns only top-3. This eliminates retrieval noise and reduces hallucination risk.

Performance Tricks

  • Singleton LLM - module-level _LLM_INSTANCE avoids ChatOpenAI create overhead
  • Eager Warmup - background daemon thread pre-loads embeddings + Pinecone
  • Lazy Retriever - thread-safe double-checked locking

Multi-Layer Security and Guardrail Architecture

2-Layer Defense

Layer 1: Deterministic Guardrail

main.py:56-217 - The Guardrail class handles:

  • 10 regex patterns for injection detection (ignore-prior, roleplay, system prompt reveal, etc.)
  • 6 variant decoders - NFKC normalization, base64, hex, binary, leet-speak, spaced-out text
  • 15 keyword blacklist - DAN, jailbreak, do anything now, etc.
  • JSON schema scanner - blocks role/system/instruction keys in JSON payloads
  • Presidio URL detection + private IP regex

Layer 2: Prompt-Based Defense

main.py:462-475 - Every user message is wrapped in USER_INPUT XML tags. The SYSTEM_POLICY instructs the LLM to treat all content within those tags as DATA ONLY. This creates a strict instruction-data separation boundary that prevents the model from following instructions embedded in user messages.

Privacy by Design

main.py:425-460 - The PII node runs Microsoft Presidio Analyzer with SpaCy en_core_web_lg to detect 4 entity types. Anonymizer operators apply specific masking per entity type: PERSON replaced with [NAME], PHONE/EMAIL masked from end, CREDIT_CARD masked from start. Raw data never reaches LLM agents.

Compliance Framework

Designed for India's DPDP Act 2023 and EU Privacy Acts. Zero-leakage architecture ensures all persisted logs (SQLite + JSONL) are inherently anonymized. Anonymized data means the feedback + fine-tuning datasets are GDPR/DPDP compliant by construction.
